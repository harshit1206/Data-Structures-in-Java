
# 66. Plus One

**Problem:** [LeetCode 66](https://leetcode.com/problems/plus-one/)  
**Language:** Java | **Difficulty:** Easy

## Approach
1. Start traversing the array from the last digit.
2. If the current digit is not `9`, increment it by `1` and return the array.
3. If the digit is `9`, change it to `0` and continue to the previous digit.
4. If all digits are `9`, create a new array of size `digits.length + 1`.
5. Set the first element of the new array to `1` and return it.

## Code
```java
class Solution {
    public int[] plusOne(int[] digits) {
        for (int i = digits.length - 1; i >= 0; i--) {
            if (digits[i] != 9) {
                digits[i]++;
                return digits;
            }
            digits[i] = 0;
        }

        int[] res = new int[digits.length + 1];
        res[0] = 1;
        return res;
    }
}
```

## Remember
- Start from the last digit because addition begins from the right.
- A digit smaller than `9` can simply be incremented.
- Adding `1` to `9` produces `0` and carries `1` to the previous digit.
- If every digit is `9`, the result needs one extra digit.
- Examples: `[1, 2, 3] → [1, 2, 4]`, `[1, 2, 9] → [1, 3, 0]`, `[9, 9] → [1, 0, 0]`.

## Complexity
- **Time:** `O(n)` — in the worst case, every digit is processed.
- **Space:** `O(1)` extra space normally; `O(n)` when a new array is required for all-`9` input.
