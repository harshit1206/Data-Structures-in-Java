
# 350. Intersection of Two Arrays II

**Problem:** [LeetCode 350](https://leetcode.com/problems/intersection-of-two-arrays-ii/)  
**Language:** Java | **Difficulty:** Easy

## Approach: Sorting + Two Pointers

1. Sort both arrays in ascending order.
2. Initialize two pointers, `i` and `j`, at index `0`.
3. Create a result array `res` to store common elements.
4. Compare `nums1[i]` and `nums2[j]`:
   - If `nums1[i] < nums2[j]`, increment `i`.
   - If `nums1[i] > nums2[j]`, increment `j`.
   - If they are equal, store the element in `res`, then increment both pointers.
5. Continue until either pointer reaches the end of its array.
6. Return only the first `k` elements of `res` using `Arrays.copyOfRange()`.

## Code

```java
import java.util.Arrays;

class Solution {
    public int[] intersect(int[] nums1, int[] nums2) {
        Arrays.sort(nums1);
        Arrays.sort(nums2);

        int i = 0;
        int j = 0;
        int[] res = new int[nums1.length];
        int k = 0;

        while (i < nums1.length && j < nums2.length) {
            if (nums1[i] < nums2[j]) {
                i++;
            } else if (nums1[i] > nums2[j]) {
                j++;
            } else {
                res[k] = nums1[i];
                k++;
                i++;
                j++;
            }
        }

        return Arrays.copyOfRange(res, 0, k);
    }
}
```

## Remember
- Sorting allows us to use two pointers efficiently.
- Move the pointer pointing to the smaller element.
- When elements match, store the element and move both pointers.
- Incrementing both pointers ensures duplicates are included only as many times as they appear in both arrays.
- `k` tracks the number of common elements found.
- `Arrays.copyOfRange(res, 0, k)` returns only the valid results.

## Complexity
- **Time:** `O(n log n + m log m)` — sorting both arrays dominates the process.
- **Space:** `O(min(n, m))` auxiliary space for the result array, with `O(n)` worst-case for `res` as implemented. Sorting space depends on the Java implementation.
