
# 283. Move Zeroes

**Problem:** [LeetCode 283](https://leetcode.com/problems/move-zeroes/)  
**Language:** Java | **Difficulty:** Easy

## Approach: Two Pointers

1. Initialize `index = 0` to track the next position for a non-zero element.
2. Traverse the array using pointer `i`.
3. If `nums[i]` is non-zero, swap it with `nums[index]`.
4. Increment `index` after placing the non-zero element.
5. Continue until the entire array is traversed.
6. All non-zero elements will be at the beginning, with zeros at the end.

## Code

```java
class Solution {
    public void moveZeroes(int[] nums) {
        int index = 0;

        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != 0) {
                int temp = nums[i];
                nums[i] = nums[index];
                nums[index] = temp;

                index++;
            }
        }
    }
}
```

## Remember
- `i` traverses the array.
- `index` tracks where the next non-zero element belongs.
- Swapping moves non-zero elements forward.
- The relative order of non-zero elements is preserved.
- The array is modified in-place.

## Complexity
- **Time:** `O(n)` — one traversal.
- **Space:** `O(1)` — constant extra space.
