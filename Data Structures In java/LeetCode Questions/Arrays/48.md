
# 48. Rotate Image

- **LeetCode:** [Rotate Image](https://leetcode.com/problems/rotate-image/)
- **Language:** Java
- **Difficulty:** Medium 🟡
- **Topic:** 2D Arrays, Matrix, In-place Algorithm

## Approach: Transpose + Reverse Each Row

### Steps
1. Find the size of the square matrix `n`.
2. **Transpose the matrix:** Swap `matrix[i][j]` with `matrix[j][i]`, starting `j` from `i + 1` to avoid duplicate swaps.
3. **Reverse each row:** Swap the leftmost and rightmost elements, moving toward the center.
4. The matrix is now rotated 90 degrees clockwise.

### Java Solution

```java
class Solution {
    public void rotate(int[][] matrix) {
        int n = matrix.length;

        // Step 1: Transpose the matrix
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int temp = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = temp;
            }
        }

        // Step 2: Reverse each row
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n / 2; j++) {
                int temp = matrix[i][j];
                matrix[i][j] = matrix[i][n - 1 - j];
                matrix[i][n - 1 - j] = temp;
            }
        }
    }
}
```

## Complexity Analysis

- **Time Complexity:** `O(n²)` — Transposing and reversing rows take O(n²) time overall.
- **Auxiliary Space:** `O(1)` — The matrix is modified in place.

## Remember

- Transpose = swap rows and columns.
- Reverse each row = move elements from left to right.
- Transpose + Reverse Rows = 90° clockwise rotation.
- No extra matrix is required.
