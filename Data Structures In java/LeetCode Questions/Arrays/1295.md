# 1295. Find Numbers with Even Number of Digits

**Problem:** [LeetCode 1295](https://leetcode.com/problems/find-numbers-with-even-number-of-digits/)  
**Language:** Java | **Difficulty:** Easy

## Approach
1. Take each number from the array.
2. Count its digits by repeatedly dividing it by `10`.
3. Stop when the number becomes `0`.
4. If `count % 2 == 0`, increment `ans`.
5. Return `ans`.

## Code
```java
class Solution {
    public int findNumbers(int[] nums) {
        int ans = 0;

        for (int i = 0; i < nums.length; i++) {
            int count = 0;
            int num = nums[i];

            while (num > 0) {
                num = num / 10;
                count++;
            }

            if (count % 2 == 0) {
                ans++;
            }
        }

        return ans;
    }
}
```

## Remember
- `num / 10` removes the last digit.
- `count++` counts each digit removed.
- `count % 2 == 0` checks if the digit count is even.
- `ans++` counts numbers with even digits.

## Complexity
- **Time:** `O(n × d)` — `n` = array size, `d` = maximum digits in a number.
- **Space:** `O(1)` — constant extra space.
