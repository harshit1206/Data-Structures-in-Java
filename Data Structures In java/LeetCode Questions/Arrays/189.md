
# 189. Rotate Array

**Problem:** [LeetCode 189](https://leetcode.com/problems/rotate-array/)  
**Language:** Java | **Difficulty:** Medium

## Approach 1: Reverse Approach

1. Calculate `n = nums.length`.
2. If `k % n == 0`, return because the array remains unchanged.
3. Update `k = k % n` to handle rotations greater than the array length.
4. Reverse the entire array.
5. Reverse the first `k` elements.
6. Reverse the remaining `n-k` elements.

### Code
```java
class Solution {
    public void reverse(int[] nums, int start, int end) {
        while (start <= end) {
            int temp = nums[start];
            nums[start] = nums[end];
            nums[end] = temp;

            start++;
            end--;
        }
    }

    public void rotate(int[] nums, int k) {
        int n = nums.length;

        if (k % n == 0) {
            return;
        }

        k = k % n;

        reverse(nums, 0, n - 1);
        reverse(nums, 0, k - 1);
        reverse(nums, k, n - 1);
    }
}
```

## Approach 2: Cyclic Replacement Approach

1. Calculate `k = k % n`.
2. Each element moves to its new index: `(currentIndex + k) % n`.
3. Save the displaced element before overwriting its position.
4. Continue moving elements to their correct positions.
5. Stop after all `n` elements have been moved.

### Code
```java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        if (n == 0) return;

        k %= n;
        int count = 0;

        for (int start = 0; count < n; start++) {
            int current = start;
            int prev = nums[start];

            do {
                int next = (current + k) % n;
                int temp = nums[next];

                nums[next] = prev;
                prev = temp;
                current = next;
                count++;
            } while (current != start);
        }
    }
}
```

## Remember
- `k %= n` handles rotations greater than the array length.
- **Reverse approach:** Uses three reversals to rotate the array.
- **Cyclic approach:** Moves elements directly to their destination indices.
- Both approaches modify the array in-place.

## Complexity

| Approach | Time | Extra Space |
|---|---|---|
| Reverse | `O(n)` | `O(1)` |
| Cyclic Replacement | `O(n)` | `O(1)` |
