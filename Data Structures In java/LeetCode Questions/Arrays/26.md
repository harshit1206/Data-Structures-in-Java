
# 26. Remove Duplicates from Sorted Array

**Problem:** [LeetCode 26](https://leetcode.com/problems/remove-duplicates-from-sorted-array/)  
**Language:** Java | **Difficulty:** Easy

## Approach
1. Initialize `k = 1` because the first element is already unique when the array is non-empty.
2. Start a loop from index `1`.
3. Compare `nums[i]` with the previous element `nums[i-1]`.
4. If they are different, a new unique element is found.
5. Store it at `nums[k]` and increment `k`.
6. Return `k`, the number of unique elements.

## Code
```java
class Solution {
    public int removeDuplicates(int[] nums) {
        int k = 1;

        for (int i = 1; i < nums.length; i++) {
            if (nums[i] != nums[i - 1]) {
                nums[k] = nums[i];
                k++;
            }
        }

        return k;
    }
}
```

## Remember
- The array is sorted, so duplicates are next to each other.
- `i` checks each element, while `k` tracks where to place the next unique element.
- `nums[k] = nums[i]` overwrites duplicates with unique elements.
- Return `k`, not the modified array.
- This solution assumes `nums.length >= 1`, as guaranteed by LeetCode 26.

## Complexity
- **Time:** `O(n)` — each element is checked once.
- **Space:** `O(1)` — uses constant extra space.
