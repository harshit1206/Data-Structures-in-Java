
# 485. Max Consecutive Ones

- **LeetCode:** [Max Consecutive Ones](https://leetcode.com/problems/max-consecutive-ones/)
- **Language:** Java
- **Difficulty:** 🟢 Easy
- **Topic:** Arrays, Counting

## Approach: Single Pass

### Steps
1. Initialize `count = 0` to track the current consecutive ones.
2. Initialize `max = 0` to store the maximum consecutive ones found.
3. Traverse the array.
4. If `nums[i] == 1`, increment `count` and update `max` if `count` is greater.
5. Otherwise, reset `count = 0` because the consecutive sequence has ended.
6. Return `max`.

### Java Solution

```java
class Solution {
    public int findMaxConsecutiveOnes(int[] nums) {
        int count = 0;
        int max = 0;
        int n = nums.length;

        for (int i = 0; i < n; i++) {
            if (nums[i] == 1) {
                count++;

                if (max < count) {
                    max = count;
                }
            } else {
                count = 0;
            }
        }

        return max;
    }
}
```

## Complexity Analysis

- **Time Complexity:** `O(n)` — Each element is visited once.
- **Auxiliary Space:** `O(1)` — Only two counter variables are used.

## Remember

- `count` tracks the current streak of consecutive ones.
- `max` stores the longest streak found so far.
- Reset `count` to `0` whenever a `0` appears.
- Update `max` while traversing the array.
