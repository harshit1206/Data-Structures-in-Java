
# 122. Best Time to Buy and Sell Stock II

**Problem:** [LeetCode 122](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-ii/)  
**Language:** Java | **Difficulty:** Medium

## Approach
1. Initialize `maxProfit = 0`.
2. Start traversing the array from index `1`.
3. Compare the current day's price with the previous day's price.
4. If the current price is higher, add the difference to `maxProfit`.
5. Continue until the end of the array.
6. Return `maxProfit`.

## Code
```java
class Solution {
    public int maxProfit(int[] prices) {
        int maxProfit = 0;

        for (int i = 1; i < prices.length; i++) {
            if (prices[i] > prices[i - 1]) {
                maxProfit += prices[i] - prices[i - 1];
            }
        }

        return maxProfit;
    }
}
```

## Remember
- Unlike Stock I, you can make multiple transactions.
- You can buy and sell multiple times, but you cannot hold multiple stocks at once.
- `prices[i] > prices[i - 1]` identifies a price increase.
- Add every positive difference to maximize the total profit.

## Complexity
- **Time:** `O(n)` — traverses the array once.
- **Space:** `O(1)` — uses constant extra space.
