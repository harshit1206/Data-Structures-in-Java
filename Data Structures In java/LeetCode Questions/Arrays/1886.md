
# 1886. Determine Whether Matrix Can Be Obtained By Rotation

- **LeetCode:** [Determine Whether Matrix Can Be Obtained By Rotation](https://leetcode.com/problems/determine-whether-matrix-can-be-obtained-by-rotation/)
- **Language:** Java
- **Difficulty:** 🟢 Easy
- **Topic:** 2D Arrays, Matrix, Simulation

## Approach: Transpose + Reverse Each Row

### Steps
1. Set `rot = 4` to check the four possible orientations.
2. Rotate the matrix 90° clockwise using transpose + reverse each row.
3. Compare every element of `mat` with the corresponding element of `target`.
4. If all elements match, return `true`.
5. Otherwise, continue rotating and checking.
6. If none of the four rotations matches, return `false`.

### Java Solution

```java
class Solution {
    public boolean findRotation(int[][] mat, int[][] target) {
        int rot = 4;

        while (rot > 0) {
            boolean ans = true;
            int n = mat.length;

            // Step 1: Transpose the matrix
            for (int i = 0; i < n; i++) {
                for (int j = i + 1; j < n; j++) {
                    int temp = mat[i][j];
                    mat[i][j] = mat[j][i];
                    mat[j][i] = temp;
                }
            }

            // Step 2: Reverse each row
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < n / 2; j++) {
                    int temp = mat[i][j];
                    mat[i][j] = mat[i][n - 1 - j];
                    mat[i][n - 1 - j] = temp;
                }
            }

            // Step 3: Compare with target
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < n; j++) {
                    if (mat[i][j] != target[i][j]) {
                        ans = false;
                        break;
                    }
                }
            }

            if (ans == true) {
                return true;
            }

            rot--;
        }

        return false;
    }
}
```

## Complexity Analysis

- **Time Complexity:** `O(n²)` — Four rotations and matrix comparisons; four is a constant.
- **Auxiliary Space:** `O(1)` — The matrix is modified in place.

## Remember

- Transpose + reverse each row = 90° clockwise rotation.
- Four orientations cover 90°, 180°, 270°, and 360° relative to the original.
- Reset `ans` for each rotation.
- Return `false` if no orientation matches.
