
# 136. Single Number

**Problem:** [LeetCode 136](https://leetcode.com/problems/single-number/)  
**Language:** Java | **Difficulty:** Easy

## Approach
1. Initialize a variable `ans = 0`.
2. Traverse every element in the array.
3. Apply the XOR operator (`^`) between `ans` and the current number.
4. Return `ans` after processing all elements.

## Code
```java
class Solution {
    public int singleNumber(int[] nums) {
        int ans = 0;

        for (int num : nums) {
            ans ^= num;
        }

        return ans;
    }
}
```

## Remember
- `a ^ a = 0` — XOR of the same numbers is `0`.
- `a ^ 0 = a` — XOR with `0` keeps the number unchanged.
- XOR is commutative and associative, so the order doesn't matter.
- Every number appearing twice cancels out, leaving the single number.

## Complexity
- **Time:** `O(n)` — traverses the array once.
- **Space:** `O(1)` — uses constant extra space.
