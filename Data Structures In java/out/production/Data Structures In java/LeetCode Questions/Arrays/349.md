
# 349. Intersection of Two Arrays

**Problem:** [LeetCode 349](https://leetcode.com/problems/intersection-of-two-arrays/)  
**Language:** Java | **Difficulty:** Easy

## Approach
1. Create two `HashSet` objects: `set` and `result`.
2. Store all elements of `nums1` in `set`.
3. Traverse `nums2` and check if each element exists in `set`.
4. If it exists, add it to `result`.
5. Since `result` is a `HashSet`, duplicate elements are automatically removed.
6. Create an array of size `result.size()`.
7. Copy the elements from `result` into the array and return it.

## Code
```java
import java.util.*;

class Solution {
    public int[] intersection(int[] nums1, int[] nums2) {
        HashSet<Integer> set = new HashSet<>();
        HashSet<Integer> result = new HashSet<>();

        for (int num : nums1) {
            set.add(num);
        }

        for (int num : nums2) {
            if (set.contains(num)) {
                result.add(num);
            }
        }

        int[] ans = new int[result.size()];
        int i = 0;

        for (int num : result) {
            ans[i++] = num;
        }

        return ans;
    }
}
```

## Remember
- `HashSet` stores only unique elements.
- `contains(num)` checks whether an element exists in a set.
- `result.add(num)` prevents duplicate intersection elements.
- The output order does not matter for this problem.
- `ans[i++] = num` stores the element and then increments `i`.

## Complexity
- **Time:** `O(n + m)` average, where `n` and `m` are the lengths of the two arrays.
- **Space:** `O(n + m)` for the sets and result array.
