
# 121. Best Time to Buy and Sell Stock

**Problem:** [LeetCode 121](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/)  
**Language:** Java | **Difficulty:** Easy

## Approach
1. Initialize `minPrice` with the first day's stock price.
2. Initialize `maxProfit = 0`.
3. Traverse the array from the first day.
4. Calculate profit by subtracting `minPrice` from the current price.
5. Update `maxProfit` if the current profit is greater.
6. Update `minPrice` if the current price is lower.
7. Return `maxProfit`.

## Code
```java
class Solution {
    public int maxProfit(int[] prices) {
        int minPrice = prices[0];
        int maxProfit = 0;

        for (int i = 1; i < prices.length; i++) {
            int profit = prices[i] - minPrice;

            maxProfit = Math.max(maxProfit, profit);
            minPrice = Math.min(minPrice, prices[i]);
        }

        return maxProfit;
    }
}
```

## Remember
- Buy before you sell.
- `minPrice` stores the lowest price seen so far.
- `profit = prices[i] - minPrice` calculates the profit if you sell today.
- `maxProfit` stores the maximum profit found.
- If prices only decrease, return `0` because no profitable transaction is possible.

## Complexity
- **Time:** `O(n)` — traverses the array once.
- **Space:** `O(1)` — uses constant extra space.
